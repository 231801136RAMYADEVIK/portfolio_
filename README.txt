HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in your browser.

HOW TO PUBLISH AND GET A SHAREABLE LINK (NETLIFY)
1. Visit https://app.netlify.com/drop
2. Sign in/create an account if prompted.
3. Drag the extracted folder containing index.html into the deploy area.
4. Netlify will publish it and show a public URL ending in netlify.app.
5. Open the URL to test it, then share the URL.

Alternative: GitHub Pages
1. Create a public repository on https://github.com.
2. Upload index.html to the repository root.
3. Go to Settings -> Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Copy the published URL from the Pages settings.
